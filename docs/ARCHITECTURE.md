## 当前关键能力

### `/api/v1/query`
- 支持 `title > q > question` 优先级
- 支持 `stream=true` 的 SSE 心跳流模式
- 支持 `subject` 参数透传到答题与复审链路
- 支持图片型选项的 URL 提取、清理、视觉摘要与按需工具查看

### LLM / Provider 层
- Chat、Completion、Embedding、Vision 四类能力独立配置
- Provider 支持：`ollama`、`openai_compatible`
- Vision 支持：
  - `openai_compatible`
  - `ollama`
- Ollama vision 输入支持：
  - URL 直传
  - 下载并编码后发送
- Provider 调用含有限重试机制
