## 数据流图

### 查题流程

```
用户请求
   │
   ▼
┌─────────────────┐
│ 1. 接收查询请求 │
│    - token      │
│    - question   │
│    - options    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 2. Token 验证   │
│    - 检查有效性  │
│    - 检查配额   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 3. 向量检索     │
│    - FAISS 搜索  │
│    - 相似度匹配 │
└────────┬────────┘
         │
    ┌────┴────┐
    │ 找到？  │
    │         │
    ▼         ▼
   Yes       No
    │         │
    │         ▼
    │    ┌─────────────────┐
    │    │ 4. AI 生成答案  │
    │    │    - LLM 调用    │
    │    │    - 提示词构建 │
    │    └────────┬────────┘
    │             │
    ▼             ▼
┌─────────────────┐
│ 5. 返回结果     │
│    - 格式化响应 │
│    - 更新配额   │
│    - 记录日志   │
└─────────────────┘
```

### RAG 对话流程

```
用户问题
   │
   ▼
┌─────────────────┐
│ 1. 向量化问题   │
│    - Embedding  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 2. 检索相关文档 │
│    - FAISS 搜索  │
│    - Top-K 选择  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 3. 构建上下文   │
│    - 拼接文档   │
│    - 添加提示   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 4. LLM 生成回答 │
│    - Chat 模型  │
│    - 流式输出   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 5. 返回并存储   │
│    - 回答文本   │
│    - 引用来源   │
│    - 历史记录   │
└─────────────────┘
```

## 模块依赖关系

```
main.py
  │
  ├─► api.py
  │     │
  │     ├─► db.py
  │     │     ├─► sqlite3
  │     │     └─► faiss + langchain_community
  │     │
  │     └─► answer_retriever.py
  │           │
  │           ├─► db.py (循环依赖已解决)
  │           └─► llm.py
  │                 └─► langchain_ollama
  │
  ├─► ui.py
  │     └─► (静态 HTML，无 Python 依赖)
  │
  └─► agents/
        │
        ├─► classification.py
        │     └─► llm.py + db.py
        │
        ├─► reviewer.py
        │     └─► llm.py
        │
        └─► rag_chat.py
              ├─► llm.py
              └─► db.py
```
